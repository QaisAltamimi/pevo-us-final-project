# PEVO.US Project Plan

## Project Overview

PEVO.US is a two-page business website for a pilot car and oversize load support service. The website will provide trucking companies, drivers, and customers with basic information about the business, the services offered, and how to contact the company.

The project will include a homepage, an About page, one external CSS file, project documentation, and a live website published through GitHub Pages.

## Project Goals

The main goals of this project are to:

- Create a clear and professional two-page website.

- Make the website easy to use on desktop and mobile devices.

- Provide useful information about PEVO.US and its services.

- Make navigation between the two pages simple and functional.

- Publish the completed website using GitHub Pages.

- Keep all project files and documentation organized in one GitHub repository.

## Risk Analysis Using TAME

### Technical Risk

One possible technical risk is that the website may have broken links, incorrect HTML, or CSS that does not display correctly. I will reduce this risk by testing both pages regularly and checking the live version before submission.

### Assumption Risk

I am assuming that GitHub and GitHub Pages will remain available during the project and that I will have access to the tools needed to complete the work. I will keep backup copies of the project files in case there is a problem.

### Management Risk

Time management is one of the main risks for this project because the work must be completed while also managing other course and personal responsibilities. I will reduce this risk by completing the project in smaller steps instead of waiting until the deadline.

### External Risk

An external risk could include internet problems or temporary problems with GitHub. I will try to complete and upload important files early so that a last-minute technical problem does not prevent the project from being submitted.

## Project Completion Criteria

The project will be considered complete when:

- index.html and about.html are finished and linked together.

- style.css is used by both pages.

- The website works on desktop and mobile devices.

- The required documentation files are complete.

- The GitHub repository is organized correctly.

- The website is published successfully using GitHub Pages.

- All required Canvas submission items are ready.
