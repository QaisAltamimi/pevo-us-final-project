# PEVO.US Project Scope Statement

## Project Overview

PEVO.US will be a simple business website for a pilot car and oversize load support service.

The website will give customers basic information about the company, the services offered, and how to contact the business.

The main goal is to create a clear and professional website that is easy to use and works correctly on both desktop and mobile devices.

The website is intended for trucking companies, drivers, and customers who may need pilot car or oversize load support services.

## Deliverables

The completed project will include:

- A main homepage named index.html
- A second page named about.html
- One external stylesheet named style.css
- A README.md file that explains the purpose of the project and includes the live website link
- A docs folder for project documentation
- A responsive website that can be viewed on both desktop and mobile devices
- Basic information about PEVO.US and the services it provides
- Contact information for customers who want to request service

## Out of Scope

The project will not include:

- Online payments or customer billing
- A customer login or account system
- Real-time GPS tracking
- A mobile application
- Advanced dispatch software
- Automated scheduling
- A database
- Live chat support

## Constraints & Assumptions

The website should be easy to use and work correctly on both desktop and mobile devices.
